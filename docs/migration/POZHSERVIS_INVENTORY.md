## Главная находка описи: это ДВА продукта в одном

Двадцать две функции делятся на две группы, и границу между ними придётся
провести до первой строчки кода, потому что для Twenty они означают совершенно
разное.

### Группа A. Инструменты для файлов — CRM-данных не касаются

Человек кладёт файл, получает разбор или другой файл. В базе не остаётся ничего,
кроме истории задач. Контрагентов, сделок и связей у этих функций нет вовсе.

| Функция | Что делает | Модель |
|---|---|---|
| Сверка таблиц | Два файла построчно, каскад из четырёх ключей | нет |
| Проверить счёт | Цена × количество, итог, НДС, сумма прописью | нет |
| Проверка реквизитов | Контрольные суммы ИНН, КПП, ОГРН, ОКПО, СНИЛС, БИК, счёта | нет |
| Заполнить по образцу | Два примера → правило → вся колонка | нет |
| Развернуть таблицу | Широкая ведомость → плоский список | нет |
| Проверить чужой файл | Затёртые формулы, СУММ мимо строк, скрытые строки | нет |
| Найти дубли | Группы похожих написаний, склейка по подтверждению | нет |
| Реестр на оплату | Реквизиты из счетов → реестр + файл клиент-банка | нет |
| Проверка документа | Орфография делового текста | LanguageTool + LLM |
| Анализ договора | Риски, ссылки на закон, редлайн-DOCX | LLM + RAG |
| Вопрос по документу | Ответ только из файла, со ссылками на страницы | LLM + RAG |
| Пакетная проверка | То же пачкой | LLM |
| Письма | Генерация на фирменном бланке | LLM |

**Для Twenty это чужеродная группа.** Twenty — про записи и связи между ними, а
здесь нет ни записей, ни связей: есть файл на входе и файл на выходе. Натягивать
их на custom objects — ошибка, которая будет мешать годами.

## Чего перенести НЕЛЬЗЯ, и это надо решить до начала

Четыре обещания, на которых построено нынешнее приложение, в Twenty не
переезжают. Каждое требует отдельного решения владельца.

### 1. Запрет выхода в интернет

Сейчас: `netguard` разрешает только петлевой адрес, любой сетевой вызов из
backend — ошибка. Это не паранойя, а раздел о конфиденциальности со штрафом в
договорах с НЛМК.

Twenty — веб-приложение с фронтендом на React, оно ходит по сети по устройству.
Отрезать его от внешнего мира можно только на уровне сети (закрытый контур,
файрвол), а не кодом. **Обещание «приложение физически не может ничего отправить
наружу» превращается в «сеть настроена так, что не может».** Это другое обещание
и другой уровень доверия.

### 2. Список файлов целостности

Сейчас: при старте сверяет свои файлы с `integrity.json` и отказывается
запускаться при расхождении. Для Twenty с его сборкой и зависимостями это
неприменимо в текущем виде.

### 3. Шифрование документов на диске

Сейчас: DPAPI на Windows, ключ привязан к машине и учётной записи. В Twenty
файлы лежат в объектном хранилище. Замена есть, но это другой механизм и другой
разговор с заказчиком.

### 4. Работа без интернета вообще

Сейчас приложение работает на одной машине без сети совсем. Twenty требует
PostgreSQL, Redis и сборку фронтенда. Самостоятельная установка «одним скриптом
на Windows-сервер» превращается в развёртывание нескольких служб.

## Что переносится дословно и стоит недорого

Хорошая новость: самая ценная и выстраданная часть — **чистая арифметика** — не
зависит ни от какого фреймворка и переписывается механически.

- контрольные суммы ИНН, КПП, ОГРН, ОГРНИП, ОКПО, СНИЛС, БИК;
- согласованность расчётного счёта с БИК по алгоритму ЦБ;
- сумма прописью;
- нормализация номеров документов и названий;
- каскад сопоставления строк при сверке;
- разбор бланка счёта 1С;
- формат выгрузки 1CClientBankExchange в windows-1251.

Это несколько тысяч строк без внешних зависимостей, и они уже покрыты тестами,
опирающимися на настоящие реквизиты. Переносятся один в один.
