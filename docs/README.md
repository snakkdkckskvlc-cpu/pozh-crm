# Документация проекта

Перенос приложения ООО «ПожСервис» на фундамент Twenty. Начато 11.08.2026.

Читать в этом порядке — каждый следующий документ опирается на предыдущий.

## 1. Зачем и для кого

- [PRODUCT_VISION](product/PRODUCT_VISION.md) — что строим, для кого, и три
  правила, без которых продукт не взлетит.
- [VISION_2027](product/VISION_2027.md) — чем это станет к августу 2027:
  три рабочих дня «до и после», что на самом деле продаётся, граница между
  ИИ и человеком, три вещи, которые сломают продукт, и чем через год мерить.
- [BRANDING](product/BRANDING.md) — цвета и логотип, снятые из работающего
  приложения. Красный `#e31e24` только для действия и проблемы.

- [ТАСК_МЕНЕДЖМЕНТ](product/ТАСК_МЕНЕДЖМЕНТ.md) — что взять у YouGile: что уже
  работает, что добавили, и чем за свои решения заплатили Vikunja и Planka.

## 4. Что выяснили про Twenty (Фаза 0)

**Свод и решения: [TWENTY_AUDIT](architecture/TWENTY_AUDIT.md).**
**План работ: [IMPLEMENTATION_PLAN](architecture/IMPLEMENTATION_PLAN.md).**

Аудит версии 0.2.1, коммит `b5826b2d` от 11.08.2026. Восемь разделов, каждый
писался отдельно и по коду, а не по сайту Twenty:
[audit/](architecture/audit/).

| Раздел | Главный вывод |
|---|---|
| 01 · данные и объекты | Свой объект = настоящая таблица PostgreSQL. **Тип поля нельзя изменить после создания.** Деньги: хранение точное, а ввод через экран портит копейки |
| 02 · задачи и канбан | Движок задач маленький: подзадач, чек-листов, зависимостей, часов и повторяемости **нет в коде вообще**. Фильтр работает до обрезки — наш дефект тут почти невозможен, но одно место найдено |
| 03 · процессы | **Подтверждение человеком есть и ждёт сколько угодно** — уборщик зависших запусков специально их пропускает. Своё согласование строить не нужно |
| 04 · агенты и модели | Движок есть и взрослый, права инструментов проверяются **в коде**. Ollama подключается штатно. **Поиска по документам нет — остаётся у нас.** Есть два обхода ограничений: интерпретатор кода и логические функции, оба выключаемы |
| 05 · расширения | **не закончен** (агент оборвался на связи) — главный незакрытый вопрос: может ли приложение добавить свой экран с загрузкой файла |
| 06 · права и безопасность | Право на поле есть, разделения «в списке нет, в карточке есть» — нет. 404 вместо 403 закрывается платным правилом уровня строки. Наше слово «роль» означает три разные вещи |
| 07 · лицензии | Из 311 платных файлов нужен ровно один кусок — «человек видит только свои записи». Весь слой расширения бесплатный. **Наш Python-сервис остаётся полностью нашим и закрытым** — лицензия разрешает отдельной оговоркой. Ограничений по числу пользователей в коде нет |
| 08 · развёртывание и тема | **Перекраска — один файл стилей, без правки исходников и пересборки:** тема читается из переменных CSS во время работы. Логотип и название — настройка из интерфейса. Сборка фронта на 8 ГБ НЕ пройдёт, собирать на боевом сервере |

## Правила, по которым ведётся эта документация

1. **Документ, из которого нельзя составить план, — потраченное время.**
2. Утверждения помечаются уровнем: проверено / следует из кода / предположение.
   Смешивать их в одном абзаце нельзя.
3. Документ обновляется в том же коммите, что и код, который он описывает.
   Расходящийся с кодом документ вреднее отсутствующего: по нему принимают
   решения.
4. Отрицательный результат записывается, а не замалчивается.
