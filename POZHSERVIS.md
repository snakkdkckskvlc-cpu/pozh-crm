# Форк ПожСервиса: что здесь наше

Это форк Twenty 0.2.1 (коммит `b5826b2d` от 11.08.2026) для ООО «ПожСервис».
**Обновлений от разработчика мы не принимаем** — решение владельца, разбор в
[ADR-002](../docs/architecture/adr/0002-fork-bez-obnovlenij.md).

Этот файл существует ради одного: **через год никто не вспомнит, что здесь наше,
а что было изначально**, и будет бояться трогать всё подряд.

## Что уже изменено

### 1. Запрет выхода в интернет (сервер)

| | |
|---|---|
| Новый файл | `packages/twenty-server/src/pozh-netguard.ts` |
| Тронут | `packages/twenty-server/src/main.ts` — вызов ПЕРВОЙ строкой |
| Тесты | `packages/twenty-server/src/__tests__/pozh-netguard.spec.ts` (24) |

**Зачем.** В договорах с ПАО НЛМК раздел о конфиденциальности со штрафом.
Поводом стала находка: телеметрия Twenty **включена по умолчанию** и шлёт
события о работе на `twenty-telemetry.com`.

**Почему в коде, а не настройкой.** Настройка — обещание, а не гарантия: её
забудут перенести на новый сервер, её вернёт новая возможность. Запрет в коде
позволяет сказать заказчику не «мы выключили», а «оно не может».

**Как отключить на время наладки:** `POZH_ALLOW_INTERNET=1`.
**Как разрешить конкретный адрес:** `POZH_ALLOWED_HOSTS=имя1,имя2` (поддомены
разрешаются вместе с именем).

### 4. Настройки

`packages/twenty-server/.env` — раздел «ПожСервис»:

| Настройка | Зачем |
|---|---|
| `TELEMETRY_ENABLED=false` | второй слой поверх запрета в коде |
| `ANALYTICS_ENABLED=false` | то же |
| `IS_BILLING_ENABLED=false` | оплата подписок нам не нужна |
| `CODE_INTERPRETER_TYPE=DISABLED` | **важно:** в исходном Twenty интерпретатор кода ВКЛЮЧЁН в режиме разработки. Наш агент не должен уметь выполнять произвольный код никогда |
| `POZH_ALLOWED_HOSTS=` | пусто: разрешение выдаётся поимённо |

### 5. Экраны службы документов внутри Twenty

| | |
|---|---|
| Новые файлы | `packages/twenty-server/src/pozh/` — ручка выдачи пропуска и её проверки |
| | `packages/twenty-front/src/pages/pozh/PozhScreenPage.tsx` — страница-рамка |
| | `packages/twenty-front/src/modules/navigation/components/PozhNavigationSection.tsx` — раздел меню |
| Тронуто | `twenty-shared/src/types/AppPath.ts` — адрес страницы |
| | `twenty-shared/src/types/ApiPath.ts` — путь ручек (чтобы его проксировали) |
| | `useCreateWorkspaceAppRouter.tsx`, `MainNavigationDrawerScrollableItems.tsx` |
| | `twenty-front/index.html` — разрешение на рамку в политике содержимого |
| Тесты | `packages/twenty-server/src/pozh/__tests__/pozh-adresa.spec.ts` (3) |

**Зачем.** Двадцать один экран остаётся в службе на Python. Переписывать их
значило бы выбросить не код, а примерно шестьсот проверок, написанных на
настоящих реквизитах компании. Twenty даёт рамку и меню.

**Список экранов спрашивается у службы**, а не хранится копией. Копия здесь
была и называлась «вторым замком» — это было преувеличением: файлы отдаёт
только служба. Копия могла лишь разойтись с оригиналом.

## Правило, за которое уже трижды платили

**В адресе — латиница. Русский только там, где его читает человек.**

Кириллица в адресе ломается МОЛЧА, и каждый раз по-новому:

| Где | Как выглядело |
|---|---|
| Имя параметра `пропуск` | сервер отвечал «Invalid HTTP request» |
| Путь в клиенте на Python | падение при кодировании |
| `@Get('экраны')` в Nest | маршрут в списке есть, запрос получает 404 |

Причина одна: браузер кодирует кириллицу всегда, а сверка адреса идёт до
раскодирования. Служба на Python исключение — она раскодирует до сверки,
поэтому её адреса остались русскими.

На это стоит замок: `pozh-adresa.spec.ts` читает исходники с диска.

      на боевом сервере он другой, иначе рамка будет молча пустой;
- [ ] логотип, название продукта и значок вкладки — ставятся настройкой из
      интерфейса, руки не дошли.

## Чего здесь НЕ надо делать

- **Не запускать `git pull` из Twenty.** Мы форк, а не копия: наши правки
  разъедутся с чужими без всякой пользы.
- **Не убирать запрет сети «чтобы заработало».** Если что-то перестало работать
  из-за него — значит оно ходило наружу, и надо понять, куда именно, а не
  снимать защиту.
- **Не править цвета в исходниках темы.** Это уже пробовали: работающая
  программа берёт их из переменных стилей, а правка исходника требует пересборки
  и всё равно перекрывается накладкой.
