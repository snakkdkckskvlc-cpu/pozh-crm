# Как поднять и посмотреть

## Быстро

```bash
cd /Users/artemharitonov/pozh-crm/twenty
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"

redis-server --daemonize yes --port 6379     # если ещё не запущен
npx nx start twenty-server                    # окно 1, порт 3000
npx nx start twenty-front                     # окно 2, порт 3001
```

Открыть: **http://localhost:3001**

Демонстрационный вход: `tim@apple.dev` (пространство Apple) или
`phil@apple.dev`. Пароль подставляется сам — в настройках стоит
`SIGN_IN_PREFILLED=true`.

## Фирменные цвета

```bash
cd /Users/artemharitonov/pozh-crm
node branding/apply-branding.mjs             # поставить
node branding/apply-branding.mjs --проверить # показать, что сделает
node branding/apply-branding.mjs --снять     # убрать
```

**Пересобирать ничего не нужно** — Twenty читает цвета из переменных стилей во
время работы. Обновите страницу в браузере.

Проверить, что подействовало (консоль браузера):

```js
getComputedStyle(document.documentElement).getPropertyValue('--t-color-blue')
```

Должно вернуть `#e31e24`, а не синий.

Накладку надо ставить заново после `git pull` в Twenty: файл кладётся в
`packages/twenty-front/public/`, а ссылка — в `index.html`.

## Если что-то не поднимается

| Признак | Причина |
|---|---|
| Ошибка про версию node | не выставлен PATH на node@24 |
| Сервер не стартует, жалуется на подключение | не запущен redis или postgres |
| Порт занят | `pkill -f "nx start"` и заново |
| Интерфейс белый | подождать: первая сборка страницы занимает время |
| Цвета не поменялись | не прогнана накладка, либо не обновлена страница |

Логи прошлого запуска: `/tmp/twenty-server.log`, `/tmp/twenty-front.log`,
`/tmp/twenty-db2.log`.

## Ограничение по железу

Памяти на машине **8 ГБ**. Сборка `twenty-ui` в неё укладывается, полная сборка
фронта не пробовалась. Если что-то падает с нехваткой памяти — уменьшать
`--max-old-space-size`, а не увеличивать: своп сделает только хуже.
