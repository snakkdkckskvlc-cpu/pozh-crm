# Границы и правила проекта

Читается исполнителем **до** того, как он что-то напишет.

## Границы, решённые в спецификации

| Часть | Владеет | Выставляет наружу | Прячет |
|---|---|---|---|
| **Служба документов** (`~/fire-safety-assistant`) | документы, расчёты, тексты договоров, кадры, табели, путевые листы, справочники старой базы | `/api/v1`: здоровье, возможности, кто-я, карточка результата | содержимое документов, базу SQLite, ключи шифрования |
| **CRM** (`~/pozh-crm/twenty`) | контрагенты, договоры-карточки, задачи, порядок работы, права доступа, меню | рамка и разовый пропуск | свою базу, устройство объектов |
| **Мост** | перевод «результат функции → карточка CRM» | одна операция: отправить карточку | формат Twenty, повторные отправки |
| **Граница договоров** | правило «текст договора не пересекает границу» | ничего | живёт внутри моста |

**Шов для проверок один: `/api/v1`.** Всё поведение между двумя системами
проверяется через него.

## Правила, которые нельзя вывести из кода

**Язык.** Всё на русском: тексты, комментарии, сообщения об ошибках, описания
правок в истории. Адреса ручек — латиницей (кириллица в пути ломает маршруты
в Twenty; проверено трижды).

**Тон.** Читатель — не программист. Запрещены без пояснения рядом: мутация,
worktree, манифест, роутер, эндпоинт, верификация, коммит, транзакция, гонка,
медиана, нормализация, идемпотентность. Если слово нельзя сказать секретарю без
объяснения — его нельзя писать и владельцу.

**Факты о заказчике не выдумывать.** Цены, реквизиты, сроки, имена, числа —
только те, что есть в коде или документах. Нет факта — ставь видимую заглушку
`[уточнить у владельца]`, а не правдоподобное число.

**Данные заказчика не публикуются никогда.** Архивы писем, тексты договоров,
корпус нормативки, база, СНИЛС и номера прав — не попадают ни в один файл, ни в
одно хранилище. Это коммерческая тайна со штрафом по договору с НЛМК.

**Новые зависимости не ставить.** Ни `npm install`, ни `pip install`. Нужна
библиотека — верни `BLOCKED` с объяснением, не ставь.

**Файлы `.py` в `scripts/` не создавать** — они покрыты проверкой целостности и
сломают запуск программы у пользователя.

**Проверка целостности.** В `~/fire-safety-assistant` файлы из `integrity.json`
менять нельзя без пересборки списка в той же правке. Файлы `.md` в этот список
не входят (проверено: 202 файла, из них `.md` — ноль), поэтому документация
безопасна.

**Полный `pytest` на этой машине не запускать** — прямое указание владельца,
ноутбук не тянет. Проверять точечно.

## Как поднять системы

```bash
# Служба документов
cd ~/fire-safety-assistant
PYTHONPATH=apps/backend/src:packages/rag/src \
  venv/bin/uvicorn fire_safety_backend.main:app --host 127.0.0.1 --port 8000

# CRM (обязательно node 24, иначе падает невнятно)
cd ~/pozh-crm/twenty
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"
npx nx start twenty-server     # порт 3000
npx nx start twenty-front      # порт 3001
```

Память на машине 8 ГБ: полная сборка интерфейса Twenty в неё не влезает.
