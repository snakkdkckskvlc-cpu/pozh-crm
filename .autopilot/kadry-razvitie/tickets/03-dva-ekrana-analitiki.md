## Что должно заработать

Кадровичка открывает «Как идут дела» и видит числа по фирме — ни одной фамилии.
Открывает «Что проверить» и видит пять строк вида «Расхождение по часам —
12 человек». Щёлкает — раскрывается по бригадам. Щёлкает ещё — фамилии. И ни
один человек больше не пропадает из таблицы молча.

## Что делаем

Нынешний `kadry_analitika.py` разбирается на две функции —
`как_идут_дела()` и `что_проверить()` — и один экран `kadry-analytics.html`
на два. **Существующее не выбрасывать:** крупные числа, объекты заказчика и
сравнение бригад «на человека» разобраны с владельцем и работают, они переезжают
как есть. Причины, по которым они такие, записаны комментарием в начале файла —
прочитай его прежде, чем менять.

Меняется три вещи:

1. **Никто не теряется.** Сейчас `_по_бригадам` молча пропускает всех, кого нет
   в составе (`if чья is None: continue`) — в июле 2026 это 11 человек из 108.
   Появляется строка **«Вне бригад»** с их часами, чтобы сумма сходилась.
2. **Офис не соревнуется.** Группы вида `офис` и `ушёл` не входят в сравнение
   бригад по выработке, но видны в общих числах.
3. **Проблемы сворачиваются в три уровня** (§6): вид → бригады → фамилии.

У строк третьего уровня — кнопки «Уволен» (ставит период `ушёл`, обратимо) и
«Разберусь» (прячет до конца месяца, рядом с видом счётчик «скрыто: N»).

## Критерии приёмки

- [ ] «Как идут дела» не содержит **ни одной фамилии**
- [ ] Сумма часов по строкам таблицы бригад, включая «Вне бригад», равна общему
      числу часов по фирме. Проверено тестом на настоящих данных
- [ ] Группы `офис` и `ушёл` не участвуют в сортировке по часам на человека
- [ ] «Что проверить»: первый уровень — только виды и количества, без фамилий
- [ ] Раскрытие вида даёт разбивку по бригадам, включая «Вне бригад» и «Офис»
- [ ] Раскрытие бригады даёт фамилии
- [ ] «Уволен» ставит период `ушёл` и убирает человека из проверок; отменяется
- [ ] «Разберусь» прячет строку до конца месяца, счётчик скрытого виден
- [ ] Проблем нет — зелёная строка «Проверять нечего», а не пустой экран
- [ ] Прошлого месяца нет — стрелка изменения не рисуется, пишется «нет данных
      за <месяц>», а не «+100%»
- [ ] Переключатель фирмы с вариантом «обе», выбор запоминается
- [ ] Существующие проверки `test_kadry_analitika.py` переписаны под новые
      функции, а не удалены
- [ ] Сквозной прогон через `TestClient` на оба экрана
